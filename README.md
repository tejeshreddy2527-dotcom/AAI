# Gemini AI Chatbot with Supabase Database

A full-stack conversational AI chatbot built with **Google Gemini** and connected to **Supabase** (PostgreSQL) for persistent chat history.

---

## Architecture Overview

```
AAI/
├── backend/
│   ├── server.py              # REST API server (Endpoints: /api/chat, /api/history, /api/reset)
│   ├── database.py            # Supabase database integration (with in-memory fallback)
│   ├── schema.sql             # SQL script to create the Supabase tables
│   ├── chatbot_cli.py         # Terminal interface
│   ├── .env.example           # Template for Gemini & Supabase keys
│   └── requirements.txt       # Optional dependencies
│
├── frontend/
│   ├── index.html             # Web chat UI with live Supabase status badge
│   ├── style.css              # Dark-theme styling & responsive chat bubbles
│   └── script.js              # Auto-fetches chat history on load & sends prompts
│
└── README.md
```

## Connecting Supabase Step-by-Step

### 1. Create the Table in Supabase
1. Open your [Supabase Dashboard](https://supabase.com/dashboard).
2. Go to **SQL Editor** -> **New Query**.
3. Open [`backend/schema.sql`](file:///c:/Users/bhava/OneDrive/Desktop/AAI/backend/schema.sql) and copy-paste the SQL content into the query editor, then click **Run**:

```sql
CREATE TABLE IF NOT EXISTS messages (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::TEXT, NOW()) NOT NULL,
    session_id TEXT DEFAULT 'default' NOT NULL,
    role TEXT NOT NULL CHECK (role IN ('user', 'model')),
    content TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_messages_session ON messages (session_id, created_at ASC);
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow anon insert and select on messages" ON messages FOR ALL USING (true) WITH CHECK (true);
```

### 2. Copy Your Supabase API Credentials
1. In your Supabase project dashboard, navigate to **Project Settings** (gear icon) -> **API**.
2. Copy:
   - **Project URL** (`https://xyzcompany.supabase.co`)
   - **anon / public key** (or service_role key)

### 3. Add to `backend/.env`
Create or open `backend/.env`:
```env
# Gemini LLM Key
GEMINI_API_KEY=your_gemini_api_key_here

# Supabase Credentials
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your_supabase_anon_key_here
```

## Running the Application

### 1. Start Backend Server
```powershell
cd backend
python server.py
```
*When running, the console will confirm:*
```
[+] Gemini API: Configured
[+] Supabase DB: Connected (https://your-project.supabase.co)
```
*(If Supabase keys are not set, it will gracefully fallback to temporary in-memory storage without crashing!)*

### 2. Open the Frontend UI
Open [`frontend/index.html`](file:///c:/Users/bhava/OneDrive/Desktop/AAI/frontend/index.html) in your browser:
```powershell
Start-Process frontend/index.html
```

- The badge next to the status dot will display **Supabase DB** in green.
- All messages sent and received are saved into your Supabase database in real-time.
- Whenever you refresh or reopen the page, the frontend automatically restores the past dialogue history from Supabase.
